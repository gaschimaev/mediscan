01
Frontend — Antarmuka Pengguna
Halaman HTML/CSS/JS statis ini berjalan di browser pengguna. User memilih foto dari perangkat, lalu menekan tombol Analisis. Foto dikirim ke backend via HTTP POST (multipart/form-data).
HTML5CSS3Vanilla JSFetch API
02
Backend — FastAPI Python
Server FastAPI menerima gambar, memvalidasi format dan ukuran, lalu meneruskan ke model AI Hugging Face. Semua proses berjalan asinkron untuk performa optimal.
FastAPIPython 3.11UvicornCORS
03
AI — Hugging Face Inference API
Model image-classification ResNet-50 milik Microsoft (tersedia gratis di Hugging Face) menganalisis gambar dan mengembalikan prediksi label beserta tingkat kepercayaan (confidence score).
Hugging FaceResNet-50Image Classification
04
Database — MySQL (lokal) / PostgreSQL (cloud)
Hasil setiap analisis disimpan ke database secara otomatis: ID unik, nama file, status kesehatan, diagnosis, dan akurasi. Riwayat dapat dilihat kapan saja di tab Riwayat.
MySQLPostgreSQLREST API
05
Deployment — Cloud Ready
Backend siap di-deploy ke AWS EC2, Google Cloud Run, Railway, atau Render. Frontend bisa di-host di Netlify/Vercel (gratis). Seluruh komunikasi menggunakan HTTPS + CORS.
AWS EC2GCPRailwayNetlify
